# Blog listing page editing notes

The URL below is for managing posts (not always for opening listing page content editing):

- https://app-na3.hubspot.com/blog/342637523/manage/posts

If **Blog listing pages** in that dropdown does not open an editor, use this reliable route:

1. In HubSpot, click **Settings**.
2. Go to **Content > Blog**.
3. Choose the target blog in **Current view / Select a blog**.
4. Open the **Templates** tab.
5. In **Blog Listing Page**, click **Actions**.
6. Use:
   - **Edit** (if available), or
   - **Change template** (to assign listing template).
7. Ensure listing template is: **Green Gage’s Blog Listing**.
8. Ensure post template is: **Green Gage’s Blog Post**.

Notes:
- If **Edit page** is unavailable, edit the coded template in Design Manager or source control.
- Blog listing pages are not normal website pages.
- A blog has one primary listing page; language variants appear under language/variant controls.
- Post grid is automatic and comes from the `contents` sequence.
- `/fr/thegreengage` and `/en/thegreengage` are blog listing paths generated by HubSpot blog multilingual settings.


Additional direct route:

Option A:
1. Go to Content > Blog.
2. In the upper-left dropdown (Blog posts), choose Blog listing pages.
3. Select the listing page variant and edit if the template supports editor mode.
